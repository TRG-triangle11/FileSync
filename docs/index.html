Features

为"懒得管"设计的备份

设好一次，之后插上硬盘就自动跑。不用记脚本、不用手动点、不用盯着进度。

认盘，不认盘符

按硬盘硬件序列号识别。换 USB 口、改盘符、换电脑，都还认得出是哪块盘。

多任务，互不干扰

任意多组 A→B、C→D，各自有独立的基线、进度和失败重试。

双向同步

两边互相补齐，以最近修改的版本为准；删除也会同步，但先留一份快照。

版本历史

被删、被覆盖的文件进 _SyncHistory，保留最近 5 份，网页里点一下就恢复。

网页控制台

任务、进度、日志、历史恢复都在浏览器里，深浅色跟随系统，手机也能看。

六道安全闸

一次要删的文件超过阈值，会先停下来问你，确认后才继续——防手滑。

How it works

三步，然后忘了它

第一次配置不超过两分钟，之后都由硬盘插入触发。

01 / SOURCE

选一个要备份的文件夹

比如 D:\工作资料。整个目录连子目录一起同步，排除规则可以单独设置。

02 / TARGET

加一个目的地

移动硬盘（按序列号认盘）或本地文件夹都行，一个源可以同时备份到多个地方。

03 / AUTO

插上就自动跑

后台常驻，插盘即触发；退出后开机自启仍会恢复，托盘右键随时手动同步。

FAQ

几个被问最多的

点开看答案。没覆盖到的，去 GitHub 提 issue。

会不会把我硬盘上的文件删光？

镜像模式会同步删除：源目录里没有的，目的地上也删。但有三道保险——只作用在该任务的目的目录内部，越不到盘根；删除前先把文件挪进 _SyncHistory 快照；单次删除比例超过阈值（默认 20%）就停下来等你确认。

硬盘换了 USB 口、盘符变了，还认得出吗？

认得出。绑定的是磁盘硬件序列号，不是盘符，所以换口、换盘符、甚至插到另一台电脑都照样识别。

少数硬盘盒不对外暴露硬件序列号，会退一步用卷序列号——这种情况下格式化后需要重新绑定一次。

需要联网吗？会上传我的文件吗？

不需要，也不上传。程序只在本机运行，网页控制台是 127.0.0.1 的本地页面，配置、日志、快照全部存在你的硬盘里。

双向同步会不会互相覆盖、丢版本？

不会用旧文件盖新文件：两边有差异时以「最近修改的那份」为准，被覆盖的那一版进快照。同步到一半拔盘也只是标记中断，下次插入重新比对，不会把半截文件当成正常状态。

一个文件夹能同时备份到几个地方？

不限。可以同时挂多块硬盘（各按序列号认各自的盘）和多个本地文件夹，每个目的地独立记录进度与失败重试；也可以配成 A→B、C→D 互不相干的多套任务。

卸载后我的设置还在吗？

卸载时会问一次：勾选「保留用户数据」，同步任务、硬盘绑定、版本快照都留在原处，重装后接着用；不勾选就连同个人数据一起清理干净。

支持 Windows 7 或 macOS 吗？

只支持 Windows 10 / 11 64 位。程序用的是系统自带的 PowerShell 5.1 与 robocopy，不需要额外安装运行时。
