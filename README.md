# FileSync

> Windows 本地文件自动同步 / 备份工具。插上你的移动硬盘就自动同步，拔掉就停，后台静默运行，网页控制台管理。

不用记命令、不用手动点、不用守着进度条。第一次配好，之后插盘即备份。

**产品页**：https://trg-triangle11.github.io/FileSync/

---

## 特点

| | |
|---|---|
| **认盘不认盘符** | 靠硬件序列号 + 卷标 + 容量三重校验识别你的硬盘，插到别的 USB 口、盘符变成 `G:` 也照样认得 |
| **插上就同步** | 后台常驻，检测到指定硬盘接入立即开跑；拔盘自动停止 |
| **多任务 / 多目的地** | 一个源目录可以同时备份到多块硬盘和多个本地文件夹；也能配成 A→B、C→D 互不相干的多套任务 |
| **双向同步** | 镜像（目的地完全跟随源）或双向（两边互相补齐，以最近修改的版本为准） |
| **删除也同步，但删得回来** | 一边删了另一边跟着删，被删 / 被覆盖的文件自动进版本历史，保留 5 份快照，网页上点一下就能恢复 |
| **六道安全闸** | 盘符、序列号、卷标、容量、文件指纹、变更幅度——删太多会先停下等你确认，避免误删整块硬盘 |
| **网页控制台** | 浏览器打开本地页面，看进度、翻日志、改设置、恢复历史版本；配置只存在本机 |
| **桌面迷你条 + 托盘** | 同步时在桌面右下角显示一条细进度条，托盘右键可立即同步、暂停、退出 |
| **无依赖** | 纯 PowerShell + 原生 Windows 组件，不需要额外运行时 |

## 系统要求

- Windows 10 / 11（64 位）
- 安装到当前用户目录，无需管理员权限
- 安装包约 11 MB

## 安装

1. 到 [Releases](https://github.com/TRG-triangle11/FileSync/releases/latest) 下载 `FileSync-Setup-64bit-vX.Y.Z.exe`
2. 双击运行，选择安装目录
3. 可选创建桌面快捷方式 / 开始菜单项
4. 安装完成后双击桌面 **FileSync** 图标启动（无黑窗口，直接进托盘）

**升级**：直接运行新版安装包覆盖安装，原来的同步任务和硬盘绑定全部保留。想更换安装目录，需先卸载再安装。

**卸载**：从「设置 → 应用」或控制面板卸载。卸载时会询问是否保留用户数据——勾选则同步任务配置、硬盘绑定、历史快照留在原处，重装后接着用。

> 安装包未做代码签名，SmartScreen 可能提示「未知发布者」，点「更多信息 → 仍要运行」即可。

## 使用

### 三步完成配置

1. **选源目录** — 要备份的文件夹，例如 `D:\我的资料`，整个目录连子目录一起同步
2. **加目的地** — 插上移动硬盘点「选择硬盘」按序列号绑定；或选一个本地文件夹做备份目标，可加多个
3. **保存** — 之后插上那块硬盘就会自动同步

### 网页控制台

托盘图标右键 →「打开控制台」，浏览器打开 `http://127.0.0.1:7792`（端口在 `console.json` 里可改）。

| 页面 | 内容 |
|---|---|
| 概览 | 当前任务、进度、速度、剩余文件、最近活动 |
| 硬盘 | 已绑定的硬盘、卷标与容量、历史版本恢复 |
| 日志 | 每次同步的明细，可按文件搜索 |
| 设置 | 任务与目的地、线程数、排除规则、进度条行为、安全闸 |

设置在**下一次同步**生效。

## 配置文件

配置在程序目录下的 `config.json`。首次启动时若不存在，会自动生成一份**空任务**的默认配置，任务由你自己添加；安装包不会带任何作者本机的目录。

```jsonc
{
  "Version": 2,
  "Tasks": [
    {
      "name": "工作资料备份",
      "source": "D:\\我的资料",
      "dests": [
        { "kind": "disk",   "sub": "我的资料", "serials": ["WD-WCC4E1234567"] },
        { "kind": "folder", "path": "F:\\备份\\工作资料" }
      ]
    }
  ],
  "Options": {
    "Threads": 8,
    "SyncMode": "mirror",          // mirror 镜像 / twoway 双向
    "FolderSyncMinutes": 0,        // 文件夹目的地定时同步（分钟），0 = 只在插盘或手动时
    "ExcludeDirs": ["$RECYCLE.BIN", "System Volume Information", ".git"],
    "ExcludeFiles": ["~$*", "*.tmp", "Thumbs.db", "desktop.ini"],
    "SafetyGuard": { "Enabled": true, "MaxDeletePercent": 20 }
  }
}
```

一般不需要手改，在网页「设置」页改完保存即可。

## 工作方式

- **触发**：轮询已接入的卷，比对任务里的 `serials`，命中即启动该任务的同步；同一时刻只跑一个任务，其余排队。
- **复制**：调用系统自带 `robocopy`（多线程、可续传）；双向模式带 `/XO`，只覆盖更旧的版本，不会用旧文件盖掉新文件。
- **删除**：与上一次的基线清单比对，源端消失的文件在目的地删除；删除前先把文件挪进版本历史目录，保留 5 份快照轮换。
- **中断**：拔盘、进程被杀都会让本次同步标记为中断，下次插入重新比对，不会把半截文件当作正常状态。

## 常见问题

**插上硬盘没反应？**
先在网页「硬盘」页确认这块盘是否已绑定。未绑定的盘不会触发同步。绑定按序列号识别，换 USB 口不影响。

**同步会不会把我的硬盘清空？**
镜像模式会删除目的地上源端已不存在的文件，但仅限该任务的目的目录内部，不会越界到盘根；删除前先做快照，变更幅度超过阈值会暂停等你确认。

**需要联网吗？**
不需要。程序只在本机运行，网页控制台也是本地地址，配置和日志都只存在本机，不上传任何数据。

**同步到一半拔了盘会怎样？**
本次同步标记为中断，已复制完成的文件是完整的，未完成的下次插入会重新比对补上。

**能同步 OneDrive / 网盘目录吗？**
可以当作普通文件夹处理，但网盘的「按需下载」占位文件可能被当作 0 字节文件复制，建议排除。
